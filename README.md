# BRAINROT.TV

A playable TikTok feed. Each scene's mechanic IS a viral meme format - remove the meme and the gameplay breaks. No meme = no game. Single-file HTML5, no dependencies, works on phone + desktop. All original characters (GOOBER, SIR NUGGET, BAO BAO, GERALD) - no borrowed IP. Built with brainrot, vibes, and a 150 BPM beat.

## Scenes
- LET GOOBER COOK (let him cook -> patience is the rule)
- NPC FARM (NPC catchphrase spam -> match the vibe)
- REACTION ROULETTE (comment culture -> match the emoji)
- ESCALATION STATION (it gets worse -> push the chaos)
- POV: MAIN CHARACTER (POV format -> do the gesture)
